# Climate Cascade Sandbox

**Category:** Climate Science Simulation

Interactive climate feedback loop simulator modeling CO₂ emissions, deforestation, ocean acidification, and methane release. Tracks six interconnected subsystems: CO₂ concentration, temperature delta, ice cover, sea level, ocean heat, and albedo. Features a live Earth visualization with temperature-colored oceans and melting ice caps, tipping point alerts, and real-time mini-charts. Trigger volcanic eruptions or solar minimums for one-time forcing events.
